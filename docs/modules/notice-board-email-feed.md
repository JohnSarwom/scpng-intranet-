## Home-screen all-staff announcement popup

Implemented in `StaffAnnouncementWelcome.tsx`, mounted by the home screen's existing NoticeBoard. After an authenticated user's fresh successful notice fetch, it offers unseen, nonexpired manual notices of category Announcement from the existing general `Announcements` list. Explicit All Officers audiences, all imported email sources, service digests, throttling subjects, future/invalid dates and blank notices are excluded. A missing audience on a manual general-board announcement means staff-wide under the existing list contract; this is not a new permission grant or a way to publish restricted email.

The popup uses the intranet maroon theme, supports light/dark mode and small screens, and displays titles, dates and sanitized plain-text previews (up to 420 characters). Read full notice opens the existing notice detail dialog. Continue, Escape, close and outside dismissal suppress the offered notices for that user on that browser. Read full notice suppresses only that item, leaving other unseen items for a later home visit. The popup evaluates once per home-screen mount after the fresh fetch, so background refresh does not interrupt work. Existing active announcements can appear once on first use; there is no arbitrary age cutoff.

Dismissed item IDs are stored in localStorage under an account-specific key, with a session-memory fallback if storage is unavailable. Bodies/titles are not persisted by this feature. This is browser-local dismissal, not a central read receipt: using another browser/device or clearing storage can show the notice again. New item IDs remain eligible. No SharePoint schema/permissions, email routing or email feature flag is changed by the popup. It requires the updated application to be deployed before it appears on the live intranet.

The manual announcement reader follows SharePoint next-page links before sorting, so notices beyond the first 100 items are not missed.

Verification: five focused eligibility/dismissal tests, one manual notice pagination test and three existing email-service tests passed; targeted lint passed; production build passed with existing font/chunk warnings. Local React StrictMode preview confirmed maroon styling, full-detail opening, reload suppression, account separation, exclusion of restricted/expired sample notices and fitting within a 390×640 viewport. Samples were local only; no tenant notices were created for popup testing.
